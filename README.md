# Poker Ledger Bot

Telegram-бот и Telegram Mini App для учёта домашних покерных игр в групповом чате: закупы, докупы, выходы со стола, сверка фишек, расчёт результатов, минимальная схема переводов и история игр.

> Статус: в разработке. Готов каркас монорепозитория, бизнес-логики пока нет.

## Возможности (V1)

- **Подключение к групповому чату.** Бот добавляется в группу. Каждый чат хранит свои настройки: ценность стека и валюту.
- **Кэш-игра.** Игроки входят в игру и делают докупы стеком или произвольной суммой. Можно выйти и вернуться. За игроков без Telegram-аккаунта можно записывать гостей.
- **Закреплённое сообщение в чате** показывает текущее состояние игры и обновляется автоматически. Кнопки «Я в игре», «Докуп» и «Отменить моё» работают прямо в чате.
- **Mini App** даёт полное управление игрой: журнал действий с отменой, завершение игры, ввод фишек на выходе.
- **Сверка фишек.** Если итоговая сумма фишек не сходится с купленной, расхождение распределяется пропорционально или относится на одного игрока.
- **Расчёт.** Результаты округляются до целых денег с нулевой суммой. Строится минимальная схема переводов, её можно править вручную с проверкой балансов.
- **История** завершённых игр с деталями. Создатель игры и админы чата могут её редактировать.
- **Приватность.** Реквизиты для переводов видят только участники конкретной игры, в чат они не попадают.
- **Языки:** русский и английский.

Позже появятся турниры, статистика и несколько параллельных игр в одном чате.

## Архитектура

```
Telegram ──(long polling)──► server (Node.js: grammY + Hono) ◄──HTTPS── Mini App (GitHub Pages)
                                  │
                                  ▼
                               SQLite
```

Бот и HTTP API работают в одном процессе. Любое действие, из чата или из Mini App, проходит через один и тот же сервисный слой. Состояние активной игры вычисляется из журнала событий.

| Каталог           | Назначение                                                                            |
| ----------------- | ------------------------------------------------------------------------------------- |
| `packages/core`   | чистые функции расчёта: итоги, корректировка расхождения, округление, схема переводов |
| `packages/shared` | общие zod-схемы, типы API, коды ошибок                                                |
| `apps/server`     | grammY-бот + Hono API, SQLite (better-sqlite3, Drizzle)                               |
| `apps/miniapp`    | React + Vite, `@tma.js/sdk-react`, TanStack Query                                     |

## Стек

TypeScript (strict) · pnpm workspaces · grammY · Hono · zod · SQLite + Drizzle · React + Vite · i18next · Vitest + fast-check · ESLint + Prettier · GitHub Actions.

## Разработка

Нужны Node 24 (см. `.nvmrc`) и pnpm через corepack.

```sh
nvm use
corepack enable
pnpm install
```

| Команда            | Что делает                                  |
| ------------------ | ------------------------------------------- |
| `pnpm dev:server`  | сервер в dev-режиме (tsx watch)             |
| `pnpm dev:miniapp` | Mini App на dev-сервере Vite                |
| `pnpm lint`        | ESLint                                      |
| `pnpm format`      | Prettier (`format:check` — только проверка) |
| `pnpm typecheck`   | `tsc --noEmit` по всем пакетам              |
| `pnpm test`        | все тесты Vitest                            |
| `pnpm build`       | сборка сервера и Mini App                   |

Переменные окружения описаны в [`.env.example`](.env.example). Скопируй его в `.env` и заполни своими значениями. Для локальной разработки нужен отдельный тестовый бот.
